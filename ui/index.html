      Steps, written down

      1. Close the game. If Angry Birds 2 is still open, press Close Angry Birds. Make sure the Key ready light is green.
      2. Back up and load. Press Back up and load. A full copy of your game's save folder is saved first.
      3. Choose your changes. Set currency (any amount), levels (up to 49), spells and hats. Levels above 49 ask you to type its on my own.
      4. Review. The app proves the new save decrypts back to exactly what you chose and shows before and after.
      5. Install. Press Install into game, then start the game (it needs internet to get past loading).
      6. Something wrong? Open Backups, pick a backup, press Restore and type 222.

      🛟 Backups

      Every install and every load makes a full copy of the game's save folder. Restore one if the game acts up. Your current files are backed up again before a restore.
